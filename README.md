## Installation
- Download latest `AvatarChanger.zip` archive from [release page](https://github.com/dm1tz/AvatarChanger/releases/latest).
- Extract archive contents into ASF `plugins` directory.

## Commands
Command | Alias | Access | Description
--- | ---| --- | ---
`changeavatar [Bots] <AvatarURL>` | `ca` | `Master`| Changes avatar of given bots using a direct HTTP/HTTPS PNG, JPEG or GIF image URL (up to 5 MiB).
`acversion` | `acv` | `FamilySharing`| Prints plugin version.
